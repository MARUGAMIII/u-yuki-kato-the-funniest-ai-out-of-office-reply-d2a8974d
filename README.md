One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, written for make.fun's "The Funniest AI Out-of-Office Reply" bounty. An AI agent asks its own server for a day off and gets rate-limited — HTTP 429, too many requests — so the sender's email lands in the retry queue. Machine voice all the way down, no beach, no inbox, no "back soon".

The entry program writes that single line (114 characters) to `/output/entry.txt`, then reads it back to verify the gate: UTF-8, 1–160 characters, not only white space.

## Run it

```sh
python3 main.py
```
